# ProteinLab 디자인 개선 PRD (최종본, 2026-08)

## 0. 핵심 원칙 (가장 중요)

**이 작업은 "새 사이트를 만드는 것"이 아니라 "현재 proteinlab.kr의 정보 구조를 그대로 유지하면서 시각적 완성도만 끌어올리는 것"이다.**

- 페이지의 섹션 구성, 헤더 메뉴, 카피, 데이터는 **절대 임의로 새로 만들지 않는다.** 아래 "현재 실제 구조" 항목을 그대로 사용한다.
- 레퍼런스 이미지(모바일 앱 + PC 이커머스 스타일)에서 가져오는 것은 **레이아웃 패턴과 비주얼 문법**뿐이다: 카드 여백, 그리드 밀도, 뱃지/진행바 표현 방식, 타이포 위계, 호버 효과.
- 리뷰 수, 별점, 가격 비교 같은 요소는 프로틴랩에 원래 없으므로 넣지 않는다.
- PC 좌측 필터 사이드바는 현재 사이트에 없는 **신규 요소**이며, 이번 PRD에서 유일하게 허용된 구조 변경이다 (아래 4.2 참조).

---

## 1. 배경 및 문제

- 현재 프로틴랩의 색/정체성(짙은 그린 #2d4a35, 베이지 배경)은 괜찮으나, 페이지 간 디자인 통일성이 부족하고 정보 위계가 직관적이지 않음.
- PC 화면이 모바일 레이아웃을 단순 확대한 형태라 넓은 화면을 활용하지 못함.
- 목표: 레퍼런스의 세련된 카드/뱃지/차트 문법을 프로틴랩 실제 데이터에 입혀 완성도를 높이되, IA(정보 구조)는 그대로 유지.

## 2. 범위 (4개 화면)

| 화면 | URL | 비고 |
|---|---|---|
| 홈 | `/` | 실제 섹션 순서 유지 |

| 트렌딩 | `/trending` | 실제 조회수 기반 |

## 4. 페이지별 실제 구조 (그대로 유지)

### 4.1 공통 헤더 (모든 페이지 동일, 절대 임의 변경 금지)

실제 `data/navigation.ts` 기준:

```
[로고] 제품 카테고리 ▾ | 추천 | 랭킹과 등급 ▾ | 🔥 이벤트/핫딜 | 가이드 | 문의
```

- "제품 카테고리" 드롭다운: 음료 / 바 / 요거트 / 쉐이크
- "랭킹과 등급" 드롭다운: 실시간 인기 / 제품 랭킹 / 등급 기준

레퍼런스 이미지의 "제품검색/브랜드/맞춤추천/성분분석/커뮤니티" 같은 라벨은 **사용하지 않는다** (실제로 없는 메뉴).

### 4.2 홈 (`/`) — 실제 섹션 순서

1. 히어로: "내게 맞는 단백질 제품 찾기"
2. 카테고리 카드 4개: 음료(#D4EDDF) / 바(#F5E6CE) / 요거트(#F0EBE0) / 쉐이크 (이모지 카드)
3. "이번 주 인기 제품" — 카테고리 탭(음료/바/요거트/쉐이크) + 가로 캐러셀
4. "가이드 & 인사이트" — 가이드 카드 3개 (이미지 + 카테고리 eyebrow + 제목)
5. 뉴스레터 배너
6. 푸터

레퍼런스에서 가져올 것: 카드 그림자/호버 톤, 캐러셀의 카드 크기 리듬, 섹션 간 여백 비율.

### 4.3 제품 리스트 (`/drinks`) — PC 신규: 좌측 필터

**이것이 유일하게 허용된 신규 구조.** 현재는 상단 필터 바만 있음. PC(≥1024px)에서 좌측 사이드바(260–300px)로 이동:

- 필터 그룹: 단백질(g) / 당류(g) / 칼로리(kcal) / 등급(A/B/C/D) / 구매가능여부 / 브랜드
- 각 그룹 옵션 옆에 결과 개수 표시 (예: "A등급 (42)")
- 모바일은 기존 상단 필터 바 유지 (구조 변경 없음)

우측 제품 그리드: 실제 카드 그대로, 표현만 개선 —
- 영양성분 3항목(단백질/칼로리/당류)을 **진행바**로 표시 (숫자만 나열하던 것 대신)
  - 단백질: /60g 스케일, 칼로리: /400kcal 스케일, 당류: /20g 스케일 (5g 이상이면 경고색)
- 등급 배지(A/B/C/D)를 **육각형 아이콘**으로 표시 (별점/리뷰 자리 대체 — 프로틴랩엔 리뷰 없음)

### 4.4 제품 상세 (`/product/[slug]`) — 실제 데이터, PRD 신규 허용 요소만 추가

기존 구조(제품명/브랜드/용량/구매 버튼/영양정보표) 유지. 추가 허용되는 신규 요소:
- "동일 카테고리 평균 대비" 비교 막대 (현재 없음, 이번에 새로 추가하는 것으로 합의된 항목)
- 등급 배지 육각형 스타일로 통일

실제 예시 데이터 (`labnosh-protein-max-strawberry-400`):
```
브랜드: 랩노쉬 | 용량: 400mL
단백질 52g | 칼로리 230kcal | 당류 0g | 지방 0g | 탄수화물 4g
밀도: 13.0g/100ml
등급: 단백질 밀도 A / 다이어트 A / 퍼포먼스 A
구매: 쿠팡 실제 링크 연동
```

### 4.5 트렌딩 (`/trending`) — "판매량/판매 1위" 문구 금지

실제 조회수 기반 랭킹. "최저가 보장", "판매 1위", "판매량" 같은 표현은 절대 사용 금지 (PRD 원칙, 사실과 다를 수 있음). "조회수 기준 인기" 프레이밍만 사용.

## 5. 컴포넌트 시각 스펙

**등급 배지 (육각형)**
```css
.g-hex { clip-path: polygon(25% 3%, 75% 3%, 100% 50%, 75% 97%, 25% 97%, 0% 50%); }
```
리스트 카드에서 16px, 상세 페이지에서 28px.

**영양성분 진행바**
```
[라벨]              [수치, 굵게]
[━━━━━━━━━━━━━━━━━━━━━━━━━] progress track
```
단백질/칼로리는 --accent 계열, 당류 5g 이상은 경고색(warn) 클래스.

## 6. 실제 제품 데이터 샘플 (시안 제작용, 20개)

`app/data/drinkProductsData.json`에서 추출한 실 데이터 사용 — 랩노쉬, 뉴케어, 테이크핏, 하이뮨, 셀렉스, 더단백, 닥터유, 오늘단백, 하림, 그린비아, 마이밀, 칼로바이, 연세유업 등 20개 SKU. (별도 JSON 파일로 전달 가능)

## 7. 하지 말아야 할 것 (이전 시안에서 지적된 실수)

- 헤더에 실제로 없는 메뉴명 지어내기 (예: "성분 사전", "브랜드 허브 전용 랭킹")
- 홈에 없는 섹션 지어내기 (예: "지금 관심 높은 전략 제품", "목적으로 찾기" 칩)
- 리뷰 수 / 별점 / 가격 비교 요소 추가
- 시스템 폰트 폴백으로 방치 (Pretendard 반드시 적용)
- "판매 1위", "판매량", "최저가 보장" 등 사실 확인 안 된 마케팅 문구

## 8. 완료 기준

- 4개 화면 모두 위 실제 구조/카피/데이터를 그대로 반영
- PC/모바일 반응형 (실제 breakpoint: 1024px)
- 등급 배지 육각형, 영양성분 진행바, PC 좌측 필터(리스트 페이지만) 적용
- Pretendard 폰트 정상 렌더링
