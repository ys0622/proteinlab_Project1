# 사용자 결정·확인 대기 목록 (ProteinLab)

사용자가 결정하거나 직접 해야 하는 것만 모은다. 결정되면 항목을 지우고 날짜와 결과를 `.claude/team-brief.md`에 반영한다. 갱신일: 2026-10-11.

## 결정이 필요한 것
- [ ] **뉴스레터 처리**: 신청 이메일이 KV(`newsletter:<이메일>`)에 쌓이기만 하고 발송 수단이 없다. 메일 서비스를 연결할지, 신청 UI를 없앨지 정한다. 개인정보처리방침에 이메일 수집 항목이 적혀 있는지도 확인 필요.
- [ ] **쿠팡 홈 폴백 15개 제품(단종)**: 2026-10-09에 23개 중 8개를 실제 링크로 교체했다. 남은 15개(`docs/coupang-links-needed-2026-10-09.md`의 3·5·6·7·8·11·12·13·17~23번)는 사용자가 단종이라고 확인했고 공용 홈 링크를 유지한다. 단종 제품을 사이트에서 내릴지, 구매 버튼을 숨길지는 아직 결정하지 않았다.
- [ ] **쿠팡 채널 ID(subId) 분리**: 케어맵과 쿠팡 계정이 공용이라 사이트별 클릭·수익이 안 갈린다. 프로틴랩용 채널 ID를 만들 일정.
- [ ] **분석 동의 기능**: `AnalyticsConsentManager`·`CookieConsentBanner`가 코드에 남아 있고 현재 쓰지 않는다. 계속 쓰지 않을지(코드 삭제), 동의 모드로 전환할지 결정. 전환하면 동의하지 않은 방문자는 GA4에서 빠지므로 수치가 낮아진다.
