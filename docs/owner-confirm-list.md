- 하이뮨 프로틴밸런스 단백질바: 성분표가 100g당 표기뿐이고 1개 중량 표기가 없다. 1개 중량이 보이는 사진이 필요하다.

- [ ] **당류 "1g 미만" 표기 방침**: 라벨이 "1g 미만"인데 데이터가 0g(단백하니 말차초코) 또는 1g(퀘스트 더블초코청크, 밸런스밀 말차초코, 단백하니 피넛버터)로 들어가 있다. 0g으로 쓰면 "당류 0g"(초록 강조)으로 보인다. 0 / 1 / "1g 미만" 표시 중 정해 주시면 일괄 반영.
- [ ] **단백하니 피넛버터·말차초코**: 두 맛 라벨 수치가 완전히 같다(38g·170kcal·12g). 맛별 원본 라벨 확인 필요.
- [ ] **힘내고 단백질바 다크초콜릿**: 라벨에 포화지방 0g·트랜스지방 1.8g으로 적혀 있어 오기로 보인다. 두 값은 고치지 않았다.
- 반영함: 바 15개 상세값(탄수화물·포화지방·식이섬유 등)을 라벨대로 교정, 단백하니 말차초코 열량 160→170·지방 6g·나트륨 180mg, 롯데 이지프로틴 에너지바 용량 45→40g.
