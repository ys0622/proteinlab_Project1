# 사용자 결정·확인 대기 목록 (ProteinLab)

사용자가 결정하거나 직접 해야 하는 것만 모은다. 결정되면 항목을 지우고 날짜와 결과를 `.claude/team-brief.md`에 반영한다. 갱신일: 2026-10-09.

## 결정이 필요한 것
- [ ] **뉴스레터 처리**: 신청 이메일이 KV(`newsletter:<이메일>`)에 쌓이기만 하고 발송 수단이 없다. 메일 서비스를 연결할지, 신청 UI를 없앨지 정한다. 개인정보처리방침에 이메일 수집 항목이 적혀 있는지도 확인 필요.
- [ ] **쿠팡 홈 폴백 23개 제품**: 쿠팡에 없는 제품은 링크 없이 두기로 했다(9/26). 23개 중 실제로 쿠팡에 있는 제품이 있으면 상품 URL을 `docs/new-shake-coupang-links-2026-09-30.csv` 같은 표로 주면 반영한다. 제품 목록은 `npm run audit:affiliate-links`로 뽑는다.
- [ ] **쿠팡 채널 ID(subId) 분리**: 케어맵과 쿠팡 계정이 공용이라 사이트별 클릭·수익이 안 갈린다. 프로틴랩용 채널 ID를 만들 일정.
- [ ] **분석 동의 기능**: `AnalyticsConsentManager`·`CookieConsentBanner`가 코드에 남아 있고 현재 쓰지 않는다. 계속 쓰지 않을지(코드 삭제), 동의 모드로 전환할지 결정. 전환하면 동의하지 않은 방문자는 GA4에서 빠지므로 수치가 낮아진다.

## 사용자가 직접 해야 하는 것

- [ ] 네이버 서치어드바이저 "웹 페이지 수집 요청": `/brands/takefit`, `/brands/hymune`, 테이크핏·하이뮨·뉴케어 41g 라인업 가이드.
- [ ] `D:\proteinlab\.cc-wt` 폴더 삭제(비어 있는 임시 폴더, 에이전트는 지우지 않는다).
- [ ] 구글 서치콘솔 색인 리포트를 2~4주 뒤 다시 캡처해 변화 확인.
