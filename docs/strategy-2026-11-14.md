## 2. 핵심 판단: 병목은 페이지 수가 아니라 '배포'와 '신뢰'다
10월 말부터 템플릿 페이지를 많이 늘리고 고쳤다. 그런데 새 페이지 한 장이 가져오는 유입은 거의 0에 가까워졌다.
- **네이버:** 첫 화면 대부분이 블로그·카페이고, 외부 사이트 자리는 2~8개다. 10/29 뒤로 '제품 + 성분' 검색어처럼 우리가 이기던 곳도 빠졌다.
- **구글:** 크롤링은 하지만 색인을 안 한다(색인 1, 크롤링됨-색인 안 됨 141).
- 두 검색엔진이 같은 신호를 보낸다. 사이트 전체를 '비슷한 페이지가 많은 제휴 사이트'로 본다는 것이다(추정, 두 곳에서 같은 방향).
- 반대로 **AI 답변(ChatGPT·네이버 AI 브리핑)은 늘고 있고 전환이 가장 높다.** ChatGPT 세션 39 → 73, 세션 대비 쿠팡 클릭 38%. 브리핑 인용 5 → 7.

그래서 "페이지를 더 만든다"에서 "적은 수의 강한 페이지 + 유입 경로를 넓힌다"로 바꾼다.

## 3. 전략 (3개 축)
### A. 강한 페이지에 모으기 (품질 신호 회복)
- 실제로 클릭을 내는 페이지(네이버 30일 클릭 1 이상, GA4 쿠팡 클릭 1 이상)를 '핵심 목록'으로 정한다. 지금까지의 분석으로 약 100~150개로 본다(추정).
- 나머지 생성 페이지 중 다른 페이지와 표가 거의 같은 것(라인업·맛별 비교·브랜드 대 브랜드 중 노출 0)은 합치거나 사이트맵에서 뺀다.
  - 9/4 canonical 통합 뒤 노출이 0이 된 전례가 있다. 그래서 목록 → Scott 승인 → 일부만 시험하고 4주 뒤 판정한다.
- 핵심 목록 페이지에는 우리만 가진 근거를 더한다. 성분표 원본 사진, 578개 전체 기준의 순위·백분위, 같은 브랜드 다른 제품과의 차이 같은 것이다.

### B. AI 답변 채널을 주력으로 (가장 빠른 전환 경로)
- ChatGPT 검색은 빙 색인을 쓴다고 알려져 있다(우리 데이터로 확인한 것은 아님). 빙 웹마스터에서 색인 수·크롤링 오류를 확인한 적이 없다. 먼저 이것부터 본다(읽기만, 제출은 승인 뒤).
- ChatGPT가 데려오는 페이지 유형(가이드·브랜드·제품·큐레이션)의 첫 문장 답·표·출처 형식을 계속 맞춘다. 11/14 템플릿 보강의 효과는 11/21에 잰다.
- 네이버 AI 브리핑에서 '뜨는데 미인용'인 질문을 매주 재고 보강한다(인용 7 → 12).

### C. 방문당 수익 올리기 (유입이 적어도 수수료가 늘게)
- 쿠팡 클릭이 가장 잘 나는 곳은 목록(63%)·브랜드(15%)다. 가이드·비교에서 목록·브랜드로 가는 동선을 다듬는다(백로그 '가이드·비교 → 목록 동선' 2차, 화면 변경이라 시안 필요).
- 비교 랜딩은 세션 대비 3%로 가장 약하고 네이버 노출도 빠졌다. 새로 만들지 않는다.

## 4. 그만할 것
- 템플릿으로 새 페이지를 한꺼번에 만드는 일(맛별·라인업·브랜드 대 브랜드). 수요 확인된 조합만 1개씩.
- 머리 검색어(브랜드명·'추천'·'순위') 제목·순위를 고치는 일.
- 효과를 재지 않고 하루에 여러 번 배포하는 일. 한 주에 큰 변경 1~2개를 하고, 다음 주에 재고 나서 넓힌다.
