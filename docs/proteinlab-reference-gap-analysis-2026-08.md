# ProteinLab 레퍼런스 대비 디자인 개선 분석

작성일: 2026-08-09  
목적: 첨부한 레퍼런스 9장과 현재 구현 화면을 비교해, ProteinLab을 모바일 중심 커머스형 서비스로 발전시키기 위한 개선 항목을 바이브코딩 작업 지시서 형태로 정리한다.

---

## 1. 결론 요약

현재 화면은 기능은 갖추고 있지만, 레퍼런스가 보여주는 "모바일 커머스 앱 같은 제품 탐색 경험"과는 아직 거리가 크다. 가장 큰 차이는 색상이나 카드 라운드 같은 세부 스타일이 아니라, 다음 네 가지다.

1. 제품이 첫 화면의 주인공이 아니다.
2. 모바일에서 구매/상세 진입 CTA가 충분히 크고 즉각적이지 않다.
3. PC 리스트는 필터 중심 쇼핑 탐색 구조가 아직 부족하다.
4. 현재 화면은 데이터베이스/검색 서비스처럼 보이고, 레퍼런스는 제품을 고르는 쇼핑 경험처럼 보인다.

따라서 다음 구현은 단순 CSS 보정이 아니라, 페이지별 정보 위계와 컴포넌트 역할을 다시 잡는 방식으로 진행해야 한다.

## 2. 레퍼런스가 공통으로 보여주는 핵심 패턴

### 2.1 브랜드 톤

- 짙은 딥그린 헤더 또는 포인트 컬러가 화면 상단에서 강하게 브랜드를 잡아준다.
- 배경은 완전 흰색보다 따뜻한 크림/샌드 계열을 사용한다.
- 카드 배경은 흰색 또는 아주 옅은 크림이며, 얇은 베이지 보더와 부드러운 그림자를 사용한다.
- 포인트 컬러는 딥그린, 골드/샌드, 브라운, 블루 CTA를 제한적으로 사용한다.

### 2.2 제품 중심성

- 제품 이미지는 작게 끼워 넣지 않고, 카드 면적의 핵심을 차지한다.
- 랭킹, 추천, 상세 모두 제품 실물 이미지가 먼저 보인다.
- 제품 카드에서 브랜드/제품명보다 "단백질, 칼로리, 당류, 등급, 구매 CTA"가 즉시 보인다.

### 2.3 모바일 커머스 UX

- 모바일은 하단 고정 내비게이션이 있다.
- 주요 CTA는 엄지로 누르기 쉬운 하단 또는 카드 하단에 크고 명확하게 배치된다.
- 필터는 화면을 차지하는 상단 폼이 아니라, 플로팅 버튼 또는 바텀시트로 처리된다.
- 제품 리스트는 작은 그리드가 아니라 큰 세로 카드 중심이다.

### 2.4 PC 탐색 UX

- PC 제품 리스트는 좌측 고정 필터 + 우측 4열 제품 그리드 구조다.
- 필터는 단백질 종류, 가격/구매 가능성, 등급, 영양 기준처럼 사용자가 고르는 기준을 그룹화한다.
- 우측 카드는 이미지, 영양 미니바, 등급 배지, CTA가 정돈되어 있다.

### 2.5 데이터 표현

- 도넛 차트, 진행바, 등급 칩, 랭킹 리본이 반복적으로 쓰인다.
- 숫자만 나열하지 않고 "좋고 나쁨"을 빠르게 스캔할 수 있게 만든다.
- 다만 ProteinLab 실제 데이터에 없는 가격, 판매량, 리뷰 수, 실시간 검색량은 절대 만들어 넣으면 안 된다.

## 3. 현재 화면의 주요 문제

### 3.1 첫 화면이 너무 설명형이다

현재 홈은 "조건에 맞는 단백질을 가장 빠르게 찾으세요"라는 큰 문구와 검색창이 중심이다. 검색 서비스로는 이해되지만, 제품 탐색과 구매 전환 관점에서는 레퍼런스 대비 약하다.

개선 방향:

- PC 홈은 검색 hero를 유지하되 오른쪽에 실제 제품 이미지 또는 제품군 비주얼을 배치한다.
- 모바일 홈은 검색보다 카테고리 진입과 인기 제품을 더 빨리 보여준다.
- 첫 화면에서 "어떤 제품을 눌러야 하는지"가 바로 보여야 한다.

### 3.2 제품 카드가 작고 힘이 없다

현재 인기 제품 카드와 카테고리 카드가 너무 작고, 이미지가 보조 요소처럼 보인다. 레퍼런스는 제품 이미지가 카드의 중심이며 CTA가 크다.

개선 방향:

- 홈 인기 카드: PC 4열 대형 카드, 모바일 세로 대형 카드.
- 리스트 카드: PC는 필터형 쇼핑 카드, 모바일은 큰 이미지 + 핵심 수치 + 구매/상세 CTA 카드.
- 제품 이미지 영역 높이를 고정해 카드 높이 흔들림을 막는다.
- 불필요한 배지 때문에 카드 크기가 달라지지 않도록 배지는 1줄 고정 또는 중요 배지만 노출한다.

### 3.3 현재 홈 인기 제품 기본값이 전략 제품과 어긋날 수 있다

현재 스크린샷에서는 인기 섹션에 요거트 탭이 선택되어 있고, 첫 노출도 요거트 중심이다. 최근 사용자의 수익화 방향은 RTD 단백질 음료, 뉴케어 올프로틴, 닥터유, 오뚜기 제품 쪽에 무게가 있다.

개선 방향:

- 홈 기본 인기 섹션은 `추천` 또는 `음료`를 우선한다.
- 뉴케어 올프로틴, 닥터유 프로, 오뚜기 데이프로틴 같은 전략 제품을 홈 캐러셀 또는 인기 섹션 상단에 일시적으로 노출할 수 있는 운영자 지정 영역을 둔다.
- 단, "판매 1위", "실시간 판매량" 같은 검증 불가 표현은 쓰지 않는다.

### 3.4 PC 리스트에 좌측 필터가 필요하다

레퍼런스 PC 리스트는 명확히 쇼핑몰 탐색 구조다. 현재처럼 상단 필터만 있으면 제품 수가 많아질수록 탐색감이 약하다.

개선 방향:

- 1024px 이상에서 좌측 필터 사이드바를 표시한다.
- 우측에는 제목, 총 제품 수, 정렬 드롭다운, 4열 제품 그리드를 둔다.
- 필터 변경은 URL query에 반영해 새로고침/뒤로가기/공유가 가능해야 한다.
- 모바일은 좌측 사이드바를 쓰지 않고 `상세 필터` 플로팅 버튼 + 바텀시트로 처리한다.

### 3.5 상세 페이지는 구매 전 최종 판단 화면으로 더 강해져야 한다

레퍼런스 상세는 이미지, 핵심 수치, 등급, 비교, 구매 CTA가 한 화면 안에 강하게 잡힌다. ProteinLab 상세도 데이터는 있지만 시각적 우선순위가 더 분명해야 한다.

개선 방향:

- PC 상세: 좌측 대형 이미지, 우측 핵심 정보/등급/영양 박스/구매 CTA.
- 모바일 상세: 상단 큰 제품 이미지, 그 아래 제품명, 핵심 수치 3개, 분석 등급, 하단 고정 `최저가 확인`.
- 쿠팡 버튼은 숨기지 말고 명확히 유지한다.
- 네이버/공식몰은 실제 링크가 있을 때만 표시한다.

### 3.6 트렌딩 페이지는 "데이터 기반 랭킹" 느낌이 부족하다

레퍼런스 트렌딩은 랭킹 화면 자체가 핵심 콘텐츠처럼 보인다. 현재 ProteinLab은 일반 섹션/카드 조합에 가까워 보일 가능성이 높다.

개선 방향:

- PC는 좌측 딥그린 사이드바 + 우측 랭킹 리스트 구조를 검토한다.
- 모바일은 큰 순위 숫자, 제품 이미지, 핵심 수치, 상승/하락 표시가 있는 카드형 리스트로 구성한다.
- 실제 데이터가 없으면 "실시간 판매량", "검색량", "리뷰 수"를 만들지 말고 `조회수 기준 인기`, `최근 조회 증가`처럼 안전하게 표현한다.

## 4. 페이지별 개선 요구사항

### 4.1 메인 페이지 `/`

PC 목표:

- 상단 헤더는 딥그린 배경으로 브랜드 존재감을 키운다.
- Hero는 왼쪽 큰 문구, 중앙/우측 검색창, 우측 제품군 비주얼로 구성한다.
- 카테고리 카드는 hero 아래 또는 모바일 우선 영역에 배치하되, 이미지가 명확히 보여야 한다.
- `이번 주 인기 제품`은 첫 스크롤 안에 노출한다.
- 인기 제품 카드는 4개 기준으로 rank, 제품 이미지, 제품명, 단백질 배지, 영양 도넛 또는 미니바, CTA를 포함한다.

모바일 목표:

- 상단은 로고 + 검색 + 메뉴/장바구니 아이콘으로 단순화한다.
- 카테고리 4개를 큼직한 카드로 노출한다.
- 바로 아래 `실시간 인기` 또는 `이번 주 인기`를 큰 세로 카드로 보여준다.
- 하단 고정 내비게이션을 제공한다.

주의:

- 장바구니 기능이 실제로 없으면 장바구니 카운트는 만들지 않는다.
- 가격 데이터가 신뢰 가능하지 않으면 가격 대신 `쿠팡 최저가 확인` 또는 `구매처 확인`을 사용한다.

### 4.2 제품 리스트 `/drinks`

PC 목표:

- 좌측 필터 260~300px, 우측 콘텐츠 영역 구조.
- 필터 그룹: 브랜드, 단백질 함량, 당류, 칼로리, 등급, 구매 가능 여부, 용량.
- 우측 상단: `단백질 음료` 또는 `드링크`, 총 제품 수, 정렬 드롭다운.
- 제품 그리드: 4열.
- 카드: 제품 이미지, 브랜드, 제품명, 용량, 단백질/칼로리/당류 미니바, 등급 배지, 쿠팡 CTA.

모바일 목표:

- 상단에 페이지명과 간단한 설명.
- 제품 카드는 1열 대형 카드.
- `상세 필터` 플로팅 버튼을 하단 우측에 배치한다.
- 필터는 바텀시트로 열고, 적용/초기화/닫기 버튼을 둔다.

주의:

- PC와 모바일에서 같은 필터 상태가 URL query로 유지되어야 한다.
- 모바일에서 필터 버튼이 쿠팡 CTA나 하단 내비게이션을 가리면 안 된다.

### 4.3 제품 상세 `/product/[slug]`

PC 목표:

- 좌측 대형 제품 이미지 영역, 우측 정보 영역 2단 레이아웃.
- 제품명 위에 브랜드명.
- 핵심 수치 3개: 단백질, 칼로리, 당류.
- 등급 배지: 밀도/다이어트/퍼포먼스 등 실제 계산 가능한 항목만.
- 하단 또는 우측에 구매 CTA: 쿠팡, 네이버, 공식몰.
- 실제 없는 링크는 노출하지 않는다.

모바일 목표:

- 상단 큰 이미지가 첫 화면을 강하게 잡는다.
- 제품명, 맛/카테고리 칩, 핵심 영양 정보가 한 번에 보인다.
- 분석 정보는 세로 리스트로 표시한다.
- 하단 sticky CTA는 `최저가 확인` 또는 `쿠팡 최저가 확인`으로 유지한다.

주의:

- 임상 효능, 질병 예방, 근거 없는 "최고" 표현 금지.
- 국제 미각상 같은 수상 이력은 실제 해당 제품에만 별도 `맛 수상 이력` 카드로 표시한다.

### 4.4 트렌딩 `/trending`

PC 목표:

- 랭킹 대시보드처럼 보이게 구성한다.
- 좌측 사이드바 또는 상단 탭으로 카테고리 전환을 제공한다.
- 랭킹 행은 순위, 제품 이미지, 제품명, 핵심 영양, 기준 데이터, CTA를 포함한다.
- 데이터 기준과 업데이트 시점을 명시한다.

모바일 목표:

- 큰 제목 `실시간 인기`.
- 순위 숫자가 큰 카드형 리스트.
- 제품 이미지, 브랜드/제품명, 단백질/칼로리, 조회 기반 트렌드 문구.
- 하단 내비게이션 유지.

주의:

- 실제 판매량/검색량/리뷰 데이터가 없으면 그래프와 상승률 숫자를 만들지 않는다.
- `조회수 기준 인기`, `최근 많이 본 제품`처럼 현재 데이터로 설명 가능한 표현을 사용한다.

## 5. 컴포넌트 개선 목록

### 5.1 새로 만들거나 분리할 컴포넌트

| 컴포넌트 | 목적 |
|---|---|
| `ResponsiveSiteHeader` | PC 딥그린 헤더와 모바일 앱형 헤더 분리 |
| `MobileBottomNav` | 홈/카테고리/검색/찜/마이페이지 또는 실제 메뉴 중심 하단 내비게이션 |
| `HomeSearchHero` | PC 검색 hero, 모바일에서는 간소화 |
| `CategoryEntryCard` | 음료/바/요거트/쉐이크 진입 카드 |
| `FeaturedProductCard` | 홈 인기/전략 제품용 대형 카드 |
| `CatalogProductCard` | PC 리스트용 쇼핑 카드 |
| `MobileCatalogProductCard` | 모바일 리스트용 대형 카드 |
| `NutritionMiniBars` | 단백질/칼로리/당류 진행바 |
| `MacroDonut` | 홈/랭킹 카드용 도넛 차트 |
| `FilterSidebar` | PC 좌측 필터 |
| `FilterBottomSheet` | 모바일 상세 필터 |
| `ProductDetailHero` | 상세 상단 대형 이미지 + 핵심 정보 |
| `TrendingRankRow` | PC 트렌딩 랭킹 행 |
| `MobileTrendingRankCard` | 모바일 트렌딩 카드 |

### 5.2 기존 컴포넌트 수정 시 주의

- `ProductCard` 하나를 전부 바꾸면 카테고리, 가이드, 추천, 랭킹이 동시에 깨질 수 있다. 먼저 variant를 분리해야 한다.
- `PurchaseLinkRow`, `PurchaseLinkButton`, `MobileStickyBuyButton`은 쿠팡 수익화에 직접 연결되므로 CTA 숨김/문구 변경 시 별도 검수한다.
- `ProductListWithFilters`는 필터/정렬/URL query/비교 기능이 섞여 있을 가능성이 높으므로 PC 레이아웃만 바꾸되 상태 로직은 보존한다.
- `HomePopularCarousel`은 홈 전략 제품 노출과 연결되므로 제품 선정 기준을 코드에 하드코딩하지 말고 운영자 지정 배열 또는 기존 인기 데이터와 결합한다.

## 6. 데이터/표현 제한

반드시 지킬 것:

- 실제 가격이 없으면 가격을 만들지 않는다.
- 판매량, 매출 순위, 검색량, 리뷰 수, 별점은 검증 가능한 데이터가 없으면 표시하지 않는다.
- 쿠팡파트너스 링크는 제품 카드와 상세 CTA에서 유지한다.
- 링크 없는 제품은 페이지를 깨지지 않게 하고, CTA를 숨기거나 `구매처 준비중`으로 처리한다.
- 뉴케어 올프로틴 국제 미각상은 실제 해당 SKU에만 표시한다.
- 대외비 매출 정보는 사이트 문구로 직접 사용하지 않는다. 내부 우선 노출 판단에만 반영한다.

표현 가능 예시:

- `조회수 기준 인기 제품`
- `최근 많이 본 제품`
- `단백질 25g`
- `당류 0g`
- `국제 미각상 3스타 수상 이력`
- `구매처 확인`
- `쿠팡 최저가 확인`

표현 금지 예시:

- `쿠팡 판매 1위`
- `실시간 판매량 급상승`
- `최저가 보장`
- `완벽한 단백질`
- `질병 예방/치료에 도움`
- 실제 데이터 없는 `리뷰 1,234개`, `검색량 12,542`

## 7. 구현 순서 제안

### Phase 0. 기준선 고정

목표: 기존 방문자 이탈과 기능 회귀를 막기 위한 사전 보호 작업.

작업:

- 현재 홈, `/drinks`, 상세, `/trending` 스크린샷 저장.
- 쿠팡 CTA가 보이는 위치 목록 작성.
- 모바일/PC 핵심 경로를 수동 점검.
- 한글 깨짐과 콘솔 오류를 먼저 확인.

완료 조건:

- 기존 쿠팡 버튼 위치가 문서화됨.
- 디자인 변경 전/후 비교 기준이 생김.

### Phase 1. 디자인 토큰과 공통 헤더/하단 내비게이션

목표: 페이지별로 따로 노는 분위기를 먼저 통일.

작업:

- 딥그린, 크림, 카드 보더, 그림자, 버튼 스타일 토큰 정리.
- PC 헤더와 모바일 헤더를 분리.
- 모바일 하단 내비게이션을 4개 대상 페이지에 공통 적용.

완료 조건:

- 기능 변경 없이 헤더/내비게이션만 시각 개선.
- 모바일에서 콘텐츠가 하단 내비게이션에 가려지지 않음.

### Phase 2. 제품 카드 시스템 분리

목표: 카드 하나 수정으로 전체가 깨지는 문제 방지.

작업:

- 홈용, 리스트 PC용, 리스트 모바일용, 트렌딩용 카드 variant를 분리.
- `NutritionMiniBars`, `MacroDonut`, `RankRibbon` 같은 작은 시각 컴포넌트 추가.
- 쿠팡 CTA는 기존 링크 동작을 유지한다.

완료 조건:

- 카드 높이 흔들림 없음.
- 이미지 없는 제품 fallback 정상.
- 쿠팡 버튼이 사라지지 않음.

### Phase 3. 홈 개편

목표: 첫 화면에서 제품 탐색과 수익화 제품 노출을 강화.

작업:

- PC hero를 검색 + 제품 비주얼 구조로 변경.
- 모바일은 카테고리 카드와 인기 제품을 우선 노출.
- 인기 제품 기본값은 `추천` 또는 `음료` 중심으로 조정.
- 뉴케어 올프로틴 등 전략 제품을 운영자 지정 추천 영역에 포함.

완료 조건:

- 모바일 첫 화면에서 카테고리 또는 인기 제품이 바로 보임.
- 쿠팡 CTA/상세 CTA가 명확함.
- 기존 SEO 메타 변경 없음.

### Phase 4. `/drinks` 리스트 개편

목표: PC는 좌측 필터 쇼핑형, 모바일은 큰 카드 + 바텀시트.

작업:

- PC 좌측 필터 사이드바 추가.
- 우측 4열 그리드 적용.
- 모바일 `상세 필터` 플로팅 버튼과 바텀시트 적용.
- URL query와 뒤로가기 유지.

완료 조건:

- PC 4열 카드 정상.
- 모바일 1열 대형 카드 정상.
- 필터/정렬/초기화/새로고침 정상.

### Phase 5. 상세 페이지 개편

목표: 구매 전 최종 판단 화면으로 강화.

작업:

- PC 좌측 이미지 + 우측 정보 구조 적용.
- 모바일 대형 이미지 hero와 sticky 구매 CTA 적용.
- 국제 미각상 등 수상 이력 카드 적용.
- 영양/분석/구매처 CTA를 명확히 분리.

완료 조건:

- 쿠팡 CTA 정상.
- 링크 없는 제품 예외 처리.
- 모바일에서 구매 CTA가 한 번에 인식됨.

### Phase 6. 트렌딩 개편

목표: 랭킹 페이지를 실제 탐색 허브로 강화.

작업:

- PC 랭킹 행 구조 적용.
- 모바일 순위 카드 구조 적용.
- 데이터 기준 문구 명시.
- 실제 없는 실시간/판매량 표현 제거.

완료 조건:

- 제품 상세/구매 CTA 연결 정상.
- 순위 기준이 명확함.
- 데이터 오해 표현 없음.

### Phase 7. 최종 QA

목표: 이전처럼 대량 변경 후 오류가 터지는 상황 방지.

검수:

- 모바일 375px, 390px, 430px.
- PC 1280px, 1440px, 1920px.
- 홈, `/drinks`, 상세, `/trending`.
- 쿠팡 링크 클릭.
- 필터/정렬/뒤로가기.
- 한글 깨짐.
- 빌드.

완료 조건:

- 쿠팡 CTA 누락 0.
- 콘솔 오류 0.
- 한글 깨짐 0.
- 기존 URL 유지.
- 모바일에서 주요 CTA 가림 없음.

## 9. 출시 전 반드시 확인할 항목

- 홈 제품 카드에서 쿠팡 파트너스 링크가 사라지지 않았는가.
- 제품 리스트 카드에서 기존 `상세보기` 역할이 쿠팡 CTA였던 위치를 잘 보존했는가.
- 상세 페이지 하단 sticky CTA가 모바일에서 정상 작동하는가.
- 뉴케어 올프로틴 국제 미각상 문구가 해당 제품에만 표시되는가.
- PC 리스트 좌측 필터가 모바일에 노출되지 않는가.
- 모바일 필터 바텀시트가 CTA를 가리지 않는가.
- 한글 깨짐이 새로 생기지 않았는가.
- 현재 없는 가격/리뷰/판매량 데이터를 만들어 넣지 않았는가.
- Search Console에 영향을 줄 URL, canonical, title을 불필요하게 바꾸지 않았는가.
