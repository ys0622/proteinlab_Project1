- 실제 코드 변경은 위 작업 ID 중 하나를 `IN_PROGRESS`로 전환한 뒤 진행한다.

- 프롬프트 0은 관리 문서와 구조 조사만 수행한 초기 준비 단계이며, PLV3-01 자체는 아직 시작하지 않았다.
