# 구글 색인 분석 (2026-10-23)

Gemini 4 Argon(agy)에 서치콘솔 데이터·기술 점검·코드 위치를 주고 분석시켰다. 원문: scratchpad `gemini_index_answer.md`. 아래는 Claude가 라이브 응답과 코드로 다시 확인한 결과만 정리한 것이다.

## 서치콘솔 실제 수치 (Aside로 읽음)
- 색인 생성됨 1 / 안 됨 755 (10/16 기준): 발견됨-미색인 625, 크롤링됨-미색인 128, noindex 2.
- 크롤링 90일 9,380건: 목적 새로고침 99%·발견 1%, Googlebot 데스크톱 47%·AdsBot 27%·스마트폰 3%, 파일 JSON 31%(/api/reviews/*, /api/track/view)·HTML 28%.
- 외부 링크 1개(kakao.com → 홈). 실적 28일 노출 42·클릭 6(브랜드 검색어만).
- 사이트맵 6개 모두 성공(sitemap.xml 730 + 분할 4개 + rss).

## 원인 판단 (확인 결과 포함)
| 원인 | Gemini 확신 | 확인 결과 |
|---|---|---|
| 새 도메인·외부 링크 1개 → 구글이 새 URL을 거의 안 가져감(발견 1%) | 높음 | **동의.** 가장 큰 원인. 데이터가 직접 보여 줌 |
| 템플릿 제품 460·일괄 비교 95 → 얇은 제휴 콘텐츠 판정(크롤링됨-미색인 128) | 높음 | **가능성 높음(추정).** 제품 설명·FAQ가 같은 문장 틀에 수치만 바뀜 |
| 헤더·모바일 메뉴 링크가 서버 HTML에 없음 → 내부 링크 단절 | 높음 | **과장.** 홈 서버 HTML(스마트폰 봇 UA)에 고유 내부 링크 52개, /drinks·/bars·/shake·/yogurt·/soymilk·/guides·/compare·/ranking 모두 있음. 서치콘솔 "내부 링크 1개"는 색인된 페이지가 홈뿐이라 생기는 결과로 보임. 단 푸터는 법적 링크만 있음(사실) |

| 홈 TTFB 1.7~3초 (제품 override KV를 1건씩 조회) | 중간 | **사실(측정값).** 다른 페이지는 0.3~0.5초 |
| 비교 페이지 canonical 불일치 | — | **사실.** /compare/newcare-vs-sellex-drink: canonical은 가이드 URL인데 JSON-LD url은 /compare 자신 |
| 사이트맵 중복(sitemap.xml 730 + 분할 4개) | 낮음 | 사실. 영향은 작음 |

## 제안 (사장님 승인 후 진행)
이번 주(작음):
1. 푸터에 카테고리·가이드·비교·브랜드 허브 링크 추가(화면 변경 → 미리보기 승인).
2. robots에 AdsBot-Google·AdsBot-Google-Mobile의 /api/ 차단 추가.
3. 비교 페이지 JSON-LD url을 canonical과 맞춤, 제품 페이지에서 비대표 비교 URL 대신 대표 URL로 링크.
4. 구글 색인 요청은 중단(네이버 수집 요청은 계속).
30일(중간):
5. 홈 TTFB: 제품 override를 한 번에 읽도록 정리.
6. sitemap.xml을 분할 사이트맵 인덱스로 정리.
7. 새 비교 페이지 일괄 생성 중단. 가이드·허브 품질 우선.
90일(큼):
8. 외부 링크 확보: 네이버 블로그 외 구글이 잘 읽는 곳(티스토리·브런치 등)에 데이터 글 + 출처 링크.
9. 조회 상위 제품 30~50개에 고유 설명 추가, 공통 FAQ 문구는 구조화 데이터에서 제외.

## 판단 지표
- 1~3주: 크롤링 통계 JSON 비율↓, 스마트폰 봇·발견 목적 비율↑.
- 3~8주: sitemap-hubs·sitemap-guides의 색인 수가 먼저 오르는지, 크롤링됨-미색인 128 감소.
- 구글 투자 비중은 네이버 유지 70~80% + 구글 20~30%가 적정(Gemini 의견에 동의).
