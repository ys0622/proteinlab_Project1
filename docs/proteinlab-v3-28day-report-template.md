## 2. 데이터 한계

- GA4 `affiliate_click`은 외부 링크 클릭이며 쿠팡 주문·수익이 아니다.
- 쿠팡파트너스는 인정 클릭·주문·수익 기준으로 집계하며 GA4와 1:1 매칭하지 않는다.
- 이번 기간의 링크 상태, 캠페인, 검색 순위 변화, 쿠키 동의/광고 차단 영향을 기록한다.

`입력: 데이터 제한 및 해석 주의사항`
