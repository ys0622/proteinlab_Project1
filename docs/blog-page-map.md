# 네이버 검색어 ↔ 블로그 글 ↔ 사이트 페이지 매핑 (2026-09-26 기준)

네이버 서치어드바이저 검색 키워드 TOP30(최근 30일) 기준입니다. 모든 URL은 라이브에서 응답 200을 확인했습니다.

## 사용 규칙
- 블로그 글의 사이트 링크는 **1순위 링크**를 본문 중간과 끝에 넣고, 보조 링크는 관련 문단에 자연스럽게 넣습니다.
- 링크 뒤에 UTM을 붙이면 GA4에서 블로그 유입을 구분할 수 있습니다. 예: `?utm_source=naver_blog&utm_medium=post&utm_campaign=<검색어 요약>` (사이트 canonical은 UTM 없는 주소라 SEO에 영향 없음)
- 글 첫 문단에 검색어를 그대로 쓰고, "성분" 검색어는 표(단백질·칼로리·당류)를 먼저 보여준 뒤 사이트에서 전체 표를 보게 유도합니다.
- 사이트에 없는 제품(예: MPI)은 글을 쓰기 전에 제품 등록이 먼저입니다.

## 블로그 글 우선순위 제안
1. **성분 검색어(CTR 8~21%)**: 2, 6, 9, 12, 18 — 노출은 작아도 클릭으로 이어지는 유형이라 글 하나당 효율이 가장 좋습니다. 브랜드별 "성분표" 글 + 브랜드 페이지 링크 조합.
2. **노출 큰 저CTR 브랜드어**: 1, 3, 4, 17, 27 — 블로그 글이 검색 상위에 올라 클릭을 나눠 갖는 것이 목표. "라인업 차이" 글 + 라인업 가이드 링크.
3. **비교 검색어(CTR 14~26%)**: 13, 19, 20 — 이미 사이트 페이지가 잘 맞는 유형이라 블로그는 사이트로 보내는 역할만 합니다.
4. **질문형**: 24, 26 — 검색량은 작지만 CTR이 높습니다. FAQ 형식 글이 적합합니다.
5. **제품 추가 필요**: 5(MPI) — 제품 등록 후 글 작성.
