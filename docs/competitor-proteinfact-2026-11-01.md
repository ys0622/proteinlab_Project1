# 경쟁 사이트 프로틴팩트(proteinfact.com) 분석·대응 (2026-11-01)

조사: 사이트맵 1,255개 전체, 홈·제품·소개·데이터 페이지, archive.org 기록, 빙 색인 수, 네이버 모바일 검색 101개(11/1). 원자료는 `.tmp-growth/pf/`(사이트맵·홈·제품 페이지 HTML 저장본).

## 1. 결론
1. **우리 데이터를 가져다 만든 사이트일 가능성이 매우 높다.** 근거는 2장.
   - 제품 712개 가운데 370개의 제품 주소(slug)가 우리와 글자 하나까지 같다.
   - 사이트맵 첫 6개 제품의 순서가 우리 공개 파일 `/products.json`과 똑같고, 겹치는 370개 중 228개가 같은 순서다.
   - 우리가 9/30 이후에 넣은 제품(두유 49개 전부 포함)은 하나도 없다.
   - 9/10에 열었고, 9월 중 우리 `/products.json`을 한 번 통째로 받아 시작한 것으로 본다.
2. **그 위에 우리보다 넓게 쌓았다.**
   - 카테고리 11개, 제품 712개, 브랜드 152개. 파우더·균형영양식·닭가슴살·스낵·빵·시리얼·아이스크림까지 다룬다.
   - 탄수화물·식이섬유·포화지방까지 채웠다.
   - 100g당 밀도로 매긴 점수와 순위, 11번가 기준 '단백질 1g당 참고가'가 있다.
   - 화면 문구와 기능도 우리와 판박이다: '쿠팡 판매처 확인 안 됨', 밀도 등급, 비교 담기, 등급 기준 페이지.
3. **아직은 작다.**
   - 빙 색인은 약 75개(우리 약 17,000개).
   - 네이버에서는 브랜드 성분 검색어 41개 중 6개에 나왔다(우리 18개). 질문형 검색어 60개에서는 0개다.
   - 다만 한 달 반 만에 "셀렉스 성분·하이뮨 성분·테이크핏 성분·더단백 성분"에 같이 뜨기 시작했다. 이 검색어군은 그동안 우리가 잘 잡던 곳이다.
4. 대응은 세 갈래다.
   - (가) 데이터가 더 새 나가지 않게 막는다. 지금도 `/products.json`에 전체 데이터가 열려 있다.
   - (나) 증거를 보존하고 법적 대응 여부는 Scott이 정한다.
   - (다) 그들이 못 하는 곳(질문형 정보 글, 성분표 사진 검증, 특가)과 그들이 앞선 곳(파우더, 상세 영양성분)에서 따라잡는다.

## 4. 대응 전략

### 가. 데이터 유출 막기 (이번 주, 화면 변화 없음)
1. **`/products.json` 줄이기.** 지금은 464개 제품의 모든 칸이 공개 파일 하나에 들어 있다(약 47만 자). 쓰는 곳은 검색·찜 화면 두 곳이고, 필요한 칸은 slug·이름·브랜드·카테고리·종류·열량·당류뿐이다. 나머지(용량·맛 구분·단백질·밀도·쿠팡 링크·공식몰·등급)는 빼고, 파일 이름도 바꿔 robots에서 막는다.
2. 제품 페이지에 데이터베이스 이용 조건을 짧게 넣는다("수치 인용 환영, 전체·상당 부분 복제 금지"). 문구는 /methodology와 약관 쪽에 넣는다. 화면 변경이라 미리보기를 거친다.
3. (선택) 데이터 지문 넣기: 실제 수치는 건드리지 않는다. 화면에 안 보이는 고유 표기, 예를 들어 slug 규칙이나 내부 ID를 심어 두면 다음에 또 가져갔을 때 증명이 쉬워진다.
4. (Scott, Cloudflare 대시보드) 같은 IP가 짧은 시간에 수백 페이지를 긁는 요청에 대한 속도 제한(rate limiting) 규칙.

### 나. 증거 보존과 대응 수위 (Scott 결정)
- 오늘 사이트맵·홈·제품 페이지 HTML을 `.tmp-growth/pf/`에 저장했다. 날짜가 남도록 저장소 밖에도 보관하고, archive.org 저장 요청을 하면 제3자 기록이 생긴다(외부 제출이라 Scott 확인 필요).
- 대응 수위 선택지:
  - ① 그냥 경쟁한다.
  - ② 사이트에 적힌 문의 이메일로 출처 표기나 삭제를 요청한다.
  - ③ 전문가 상담 후 법적 조치를 한다. 그들 스스로 저작권법 93조를 내세우고 있어 우리 쪽 주장도 같은 조문이다.
- 이것은 법률 판단이 아니다. ③을 고르면 변호사 상담이 먼저다. 추천은 ①+②다. 시간이 덜 들고, 요청 메일 자체가 기록이 된다.

| 6 | **주간 감시** | 토요일 주간 점검에 "프로틴팩트가 같이 나온 검색어 수"를 넣는다(이번 101개 검색어 그대로) |
