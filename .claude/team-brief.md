# ProteinLab 팀 공통 브리핑

검수 에이전트는 작업 전에 이 파일을 읽는다. 여기 적힌 내용은 이미 확인된 사실이므로 다시 조사하지 말고, 새로운 발견만 보고한다.

## 에이전트 운영 구조
- 기본 구성은 메인 작업자 1명과 통합 검수자 2명이다.
- 메인 작업자는 구현, 테스트, 커밋, 배포를 담당한다. 일반적인 코드 수정은 메인 작업자만 수행한다.
- `seo-ops-reviewer`는 기술 SEO, 빌드, 배포 후 라이브 응답, 링크·이미지·성능·데이터 무결성을 통합 검수한다.
- `content-growth-reviewer`는 콘텐츠 정확성·중복·표현 위험과 검색 유입·CTR·전환 흐름을 통합 검수한다.
- 변경 유형과 직접 관련된 검수자만 호출한다. 대규모 개편이나 출시 전 전체 검수에서만 두 검수자를 함께 호출한다.
- 동일 변경에 대한 재검수는 수정 완료 후 한 번만 한다. 이미 이 문서에 기록된 사실은 재조사하지 않는다.
- 검수자는 읽기 전용이다. 파일 수정과 배포는 메인 작업자만 한다.

## 호출 기준
- 일반 코드 수정: 메인 작업자만 사용
- SEO, 라우팅, 메타데이터, 빌드, 배포, 라이브 장애: `seo-ops-reviewer`
- 가이드, FAQ, 제품 데이터, 검색 성과, 전환 문구: `content-growth-reviewer`
- 대규모 개편 또는 출시 전 회귀 검수: 두 검수자 모두 사용
- GA4·서치콘솔·네이버 데이터 분석은 새로운 데이터나 스크린샷이 제공된 경우에만 수행

## 사이트
- proteinlab.kr — 단백질 음료·바·요거트·쉐이크 비교 사이트 (Next.js App Router, Cloudflare Workers via OpenNext, Windows에서 배포).
- 수익: 쿠팡파트너스, 애드센스. 제품 DB는 `app/data/*ProductsData.json`, 슬러그→이미지는 `slugToImage.json`/`slugToBarImage.json`.
- 트래픽은 네이버 90% 이상, 구글 유입은 사실상 0 (GA4 28일 기준 google/organic 5명).

## 이미 확인·해결한 것 (다시 찾지 말 것)
- robots는 `NEXT_PUBLIC_DISABLE_INDEXING`으로 fail-open. 현재 라이브 robots.txt·메타는 정상.
- `/compare/[slug]`와 가이드 페이지 중복 5쌍은 canonical 오버라이드로 처리됨. `/compare`와 `/cookie-settings` 누락도 수정됨.
- `ProductCard`에 실제 `<a href>`가 없던 문제, `ProductListWithFilters`가 정적 빌드에서 Suspense fallback(null)로 빈 HTML을 내보내던 문제는 수정됨(`/drinks /bars /shake /yogurt /products /recommend`는 `force-dynamic`).
- FAQ 스키마는 market-insights, intake-strategy-health 전체와 얇았던 요거트·바 가이드 6개에 적용됨.
- 제품 이미지 62개를 WebP로 변환함.
- 구글 서치콘솔: 수동 조치 없음. 색인 1개, 미색인 814개(발견됨-미크롤링 581, 크롤링됨-미색인 168, NOINDEX 캐시 62). 판단: 기술 버그가 아니라 도메인 신뢰도(백링크 거의 0)와 시간 문제.
- R2 ISR 캐시는 사용자가 계정 설정을 원하지 않아 보류함(페이지 캐시 MISS와 느린 TTFB는 알려진 상태).

## 하지 말아야 할 것
- 개발 서버(`next dev`)만 보고 "정상"이라고 결론 내리지 말 것. 프로덕션 빌드와 라이브 응답(curl, Googlebot UA)으로 확인할 것. 개발 모드는 정적 렌더링 문제를 숨긴다.
- 애드센스 추가가 SEO에 도움이 된다고 제안하지 말 것(무관하며 속도만 해친다).
- 확인하지 않은 수치·순위·경쟁사 정보를 사실처럼 쓰지 말 것.
- 파일을 수정하지 말 것. 검수 에이전트는 읽기 전용이며 발견사항만 보고한다.

## 보고 형식
1. 발견사항을 심각도 순(치명 / 중요 / 사소)으로 나열
2. 각 항목에 근거(파일:줄, curl 결과, 스크린샷 수치)를 붙일 것
3. 확인된 사실과 추정을 구분해서 표기
4. 수정 제안은 한 줄로. 수정은 메인 세션이 한다

## 알려진 데이터 메모
- 네이버 검색어 (30일): 테이크핏 노출 16,031·CTR 0.6%, 하이뮨 9,001·0.4%, 테이크핏 맥스 2,870·0.5%. "X 성분/비교" 형태는 CTR 12~34%로 높다.
- 유입 상위 페이지가 비교 페이지인데 체류 9~13초로 거의 바로 이탈한다.
- 제품 DB 수동 확인 대기 항목은 메모리 파일(`MEMORY.md`)의 "Pending Manual Review" 참고.
